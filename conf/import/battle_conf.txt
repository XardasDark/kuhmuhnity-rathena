// --- Raten --------------------------------------------------

// Drops: normale Items 2x, Karten und MVP-Drops bleiben selten (1x),
// damit sie wertvoll bleiben.

item_rate_use: 200
item_rate_equip: 200

// Ein Kill gibt höchstens ein Level (klassisches Verhalten).

// Todesstrafe: 1 % des aktuellen Levels (klassisch).
// Bei Zero ist der Tod der größte Bremsklotz beim Leveln.

// --- Party-Spiel ---------------------------------------------
// Zero belohnt Gruppenspiel. Jedes weitere Mitglied in einer
// Even-Share-Party gibt +10 % Gesamt-EXP.
// Beispiel 5er-Party: 140 % / 5 = 28 % pro Person statt 20 %.

// AFK-Mitglieder (5 Minuten ohne Aktion) bekommen keinen EXP-Anteil.

// --- Komfort --------------------------------------------------
// Monster-HP in Prozent und Monster-Level neben dem Namen (2 = HP %, 4 = Level, 6 = beides)
